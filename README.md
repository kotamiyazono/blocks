# BLOCKS

角でつなげて広げていく、2 人用のブロック配置ゲーム。14×14 の盤に 21 種類のピースを置き合い、
手元に残ったマスが少ないほうが勝ち。

3 つの遊び方があります。

| 遊び方 | 内容 |
| --- | --- |
| **ひとりで遊ぶ** | CPU と対戦。強さは「やさしい / ふつう / つよい」の 3 段階、先手・後手も選べます |
| **対面で遊ぶ** | 端末を机に置き、向かい合わせに座って 2 人で。実物と同じく盤は回さず、各自の手元に自分のピースが並びます |
| **オンラインで遊ぶ** | 部屋を作って招待 URL を送るだけ。相手が開いた瞬間にはじまります。打った文字がそのまま相手に見える簡易チャット付き |

## 色

対戦前に 6 色（むらさき／オレンジ／ブルー／グリーン／ピンク／ターコイズ）から選べます。
ひとりなら自分の色、対面なら先手・後手それぞれ、オンラインなら部屋を作る側と参加する側が
それぞれ選びます（相手が使っている色は選べません）。選んだ色は次に遊ぶときも覚えています。

色は見た目だけの話なので、スタイルが参照している 2 つの変数を差し替えるだけで
盤・持ちピース・結果画面までまとめて変わります。ゲームの進行には一切関わりません。

## ルール

1. 最初の一手は、自分の色の印があるマスを必ず覆うように置く
2. 2 手目からは、**自分の駒と角が触れる**ように置く
3. **自分の駒と辺で接してはいけない**（相手の駒とは辺で接してよい）
4. 置ける場所が無くなった人は自動的に飛ばされ、両方が置けなくなったら終了
5. 手元に残ったマスが少ないほうの勝ち

## 操作

持ちピースは横に流れるカルーセルで、**真ん中に来たものが今のピース**。中央に近いほど大きく濃くなります。
今の盤面で置ける場所が無いピースは色が抜けて表示されます。

**どこに置くかはアプリが決めません。** 選んだピースは盤をタップして初めて盤上に現れます。
置ける場所を先回りして提示すると、手番が来た瞬間から確定できる状態になり、
考えずに「置く」を押すだけで進んでしまうためです。

| したいこと | 操作 |
| --- | --- |
| ピースを選ぶ | カルーセルを横に流す／ピースをタップ |
| 置く場所を決める | 盤をタップ。そのままなぞって微調整 |
| 回転 | 駒をタップ（回転 4 通り → 反転した 4 通り、と順に一巡します） |
| 反転 | 駒を長押し |
| 確定 | 「置く」 |

PC では矢印キーで移動、`R` 回転、`F` 反転、`Enter` 決定、`Z` 待った、`Esc` 選択解除。

残りマスの数字は表示していません。**手元のカルーセルに残っているピースそのものが「残り」**なので、
数で言い直す必要がないためです。最終的な数字は結果画面に出ます。

## 技術的な構成

ビルド不要の素の ES モジュールと、Vercel Functions だけで動きます。

```
index.html          画面
styles.css          見た目
js/rules.js         ルール（ブラウザとサーバの両方が同じものを読む）
js/ai.js            CPU の思考
js/view.js          盤面とトレイの描画
js/online.js        通信とポーリング
js/app.js           画面遷移と対局の進行
api/room.js         オンライン対戦の部屋（Vercel Blob）
test/rules.test.mjs ルールの検証
```

## ひとこと（オンライン対戦のみ）

盤の下に 1 行だけの入力欄があります。**送信ボタンはなく、打っている文字がそのまま相手に流れていきます。**
残るのは「いま言っていること」だけで、会話の履歴はどこにも持ちません。部屋を閉じれば一緒に消えます。

打ち合っている間だけ通信の間隔が詰まるので、普段は無駄な通信をしません。

### オンライン対戦について

対局中の盤面だけをプライベートな Vercel Blob に置き、**勝敗も棋譜もプレイヤー情報も保存しません。**

- 対局が終わって画面を離れると、その場で盤面を削除します
- 消し損ねた部屋も、2 時間（終局後は 5 分）触られなければ次に読まれた時点で消えます
- 読み取りは `useCache: false` で常に最新を取得し、書き込みは ETag による条件付き書き込みで
  両者の同時着手による破損を防いでいます
- 着手はサーバ側でルールを一から検証しているので、クライアントを書き換えても不正な手は通りません

## 開発

```bash
npm install
npm test          # ルールの検証
npx vercel dev    # ローカルで API ごと動かす
```

初回だけ、Blob ストアの用意が必要です。

```bash
npx vercel link
npx vercel blob create-store blocks-rooms --access private --yes
npx vercel env pull .env.local
```
