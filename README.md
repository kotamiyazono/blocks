# BLOCKS

角でつなげて広げていくブロック配置ゲーム。21 種類のピースを置き合い、
手元に残ったマスが少ないほうが勝ち。

| 人数 | 盤 | 開始点 |
| --- | --- | --- |
| **2 人**（ブロックス デュオ） | 14×14 | 盤の少し内側の 2 点 |
| **4 人**（本家ブロックス） | 20×20 | 四隅 |

3 つの遊び方があります。

| 遊び方 | 内容 |
| --- | --- |
| **ひとりで遊ぶ** | CPU と対戦。2 人戦（先手・後手を選択）と 4 人戦（自分＋CPU3 人）。強さは「やさしい / ふつう / つよい」の 3 段階 |
| **対面で遊ぶ** | 端末を机に置き、向かい合わせに座って 2 人で。実物と同じく盤は回さず、各自の手元に自分のピースが並びます |
| **オンラインで遊ぶ** | 部屋を作って招待 URL を送るだけ。**受け取った人は開いた瞬間に席につきます。**2 人戦と 4 人戦を選べます。打った文字がそのまま相手に見える簡易チャット付き |

色は席で決まります（先手から むらさき／オレンジ／ブルー／グリーン）。
選ばせると手数が増えるだけなので、選択の余地は置いていません。

### 4 人戦で人が揃わないとき

部屋を作った人が「空いた席を CPU にして始める」を押すと、その時点で空いている席を
CPU が引き受けます。2 人しか集まらなくても 4 人戦が遊べます。

サーバ側で CPU に考えさせることもできますが、今は**CPU の思考を部屋を作った人の端末が回しています。**
サーバはその代打ちを部屋を作った人にだけ許しており、他の参加者が CPU 席を動かすことはできません。
裏を返すと、部屋を作った人が離脱すると CPU も止まります。

## ルール

1. 最初の一手は、自分の色の印があるマスを必ず覆うように置く（4 人戦なら自分の隅）
2. 2 手目からは、**自分の駒と角が触れる**ように置く
3. **自分の駒と辺で接してはいけない**（他の色の駒とは辺で接してよい）
4. 置ける場所が無くなった人は自動的に飛ばされ、全員が置けなくなったら終了
5. 手元に残ったマスが少ない順に順位が決まる

## 操作

持ちピースは横に流れるカルーセルで、**真ん中に来たものが今のピース**。中央に近いほど大きく濃くなります。
今の盤面で置ける場所が無いピースは色が抜けて表示されます。

**どこに置くかはアプリが決めません。** 選んだピースは盤をタップして初めて盤上に現れます。
置ける場所を先回りして提示すると、手番が来た瞬間から確定できる状態になり、
考えずに「置く」を押すだけで進んでしまうためです。

| したいこと | 操作 |
| --- | --- |
| ピースを選ぶ | カルーセルを横に流す／ピースをタップ |
| 置く場所を決める | 盤をタップ。そのままなぞって微調整 |
| 回転 | 駒をタップ（回転 4 通り → 反転した 4 通り、と順に一巡します） |
| 反転 | 駒を長押し |
| 確定 | 「置く」 |

PC では矢印キーで移動、`R` 回転、`F` 反転、`Enter` 決定、`Z` 待った、`Esc` 選択解除。

残りマスの数字は表示していません。**手元のカルーセルに残っているピースそのものが「残り」**なので、
数で言い直す必要がないためです。最終的な数字は結果画面に出ます。

## 技術的な構成

ビルド不要の素の ES モジュールと、Cloudflare Workers（静的配信）・Durable Objects（部屋）だけで動きます。

```
public/js/room.js          オンライン対戦の段取り

```

## ひとこと（オンライン対戦のみ）

盤の下に 1 行だけの入力欄があります。**送信ボタンはなく、打っている文字がそのまま相手に流れていきます。**
残るのは「いま言っていること」だけで、会話の履歴はどこにも持ちません。部屋を閉じれば一緒に消えます。

盤面は Durable Object から変化したときだけ push されるので、待っている間も無駄なポーリングをしません。

### オンライン対戦について

対局中の盤面だけを部屋コードごとの Durable Object に置き、**勝敗も棋譜もプレイヤー情報も保存しません。**

- 対局が終わって画面を離れると、その場で盤面を削除します
- 消し損ねた部屋も、2 時間（終局後は 5 分）触られなければ部屋自身の alarm で消えます
- 同じ部屋への操作は 1 つずつ順番に処理されるので、同時着手でも盤面が壊れません
- 対局中は Hibernation WebSocket で盤面を push し、ひとことだけを軽い差分メッセージで流します
- 着手はサーバ側でルールを一から検証しているので、クライアントを書き換えても不正な手は通りません

## 開発

```bash
npm install
npm test           # ルールの検証（2 人戦・4 人戦）
npx wrangler dev   # ローカルで API ごと動かす
BLOCKS_URL=http://localhost:8787 npm run test:online
```

`npm test` は通信を伴わないルールの検証で、盤・向き・合法手・終局・順位まで確かめます。
`npm run test:online` は実際のサーバに本物のリクエストを投げ、部屋の作成から
着手の権限、終局、後片付けまでを通します。既定では本番に向くので、
別の環境を見るときは `BLOCKS_URL=http://localhost:8787 npm run test:online` のように指定します。

Cloudflare にログインして公開するときは、次のコマンドを使います。用意する環境変数はありません。

```bash
npx wrangler login
npx wrangler deploy
```

## 公開

**`main` に push すれば公開されます。** それが唯一の手順です。
Cloudflare が GitHub を見ていて、push のたびに公開し直します（Workers Builds）。
ビルド工程は無いので、走るのは `npx wrangler deploy` だけです。

用意する環境変数も secret も 1 つもありません。

手元から `npx wrangler deploy` を直接打つこともできますが、それは GitHub 連携が
壊れているときの逃げ道です。普段は push で済ませます。
